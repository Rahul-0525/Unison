Trouble connecting? (Quick 1-Minute Fixes)
⚡ Quickest Fix

Use Phone Hotspot: If your home Wi-Fi blocks devices from seeing each other, turn on your phone's Personal Hotspot, connect this laptop to it, and scan the QR code. It works 100% of the time without router restrictions!

🌐 Address Check

Make sure the phone opens the exact http:// link (not https). If the page doesn't load, try tapping an alternative address chip above (usually starting with 192.168...).

🛡️ Firewall

If Windows showed a security alert when starting the server, make sure you clicked "Allow Access" on both Private and Public networks.

🔇 No Sound on Phone?

Mobile browsers (iOS Safari & Chrome) require a screen touch to unlock audio. Make sure phone media volume is up and tap "Tap to resume audio" if visible.
